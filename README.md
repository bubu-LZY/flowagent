# FlowAgent — 多智能体 draw.io 流程图工具

> 一句话：用 6 个 AI 智能体 + draw.io 画布协作，让你说的"画一张流程图"自动拆解、画图、评审、沉淀经验。

## 它能做什么

- 📝 **一句话需求** → 35 节点可视化流程图，**不用手画**
- 🤖 **多智能体协作**：项目经理 / 设计助手 / 架构师 / 评审员 / 执行代理 / 文档员 / 小白
- 🛠️ **可插拔 Skill**：自带 `drawio-architecture` / `AIGuide 画图专家`，拖入 zip/.md 即可加新 Skill
- 🧠 **自动沉淀经验**：每轮对话自动总结可复用经验，弹窗让你勾选入库
- 🔍 **强制看图评审**：评审员必须调 `analyze_diagram_image` 真实看图，不能口头说"通过"
- ⚡ **画图铁律 + lint 自检**：节点圆角矩形 / 连线圆角直角 / 标签落中段 / 无重叠 / 6 步法
- 🎯 **仅画图模式**：跳过所有讨论直接画

## 30 秒试用

```bash
npm install
npm run dev        # 启动 Web 版（端口 5173）
# 或
npm run build:electron  # 打包 Windows 安装包到 release/0.1.0/
```

打开应用后到 设置 → 模型配置 添加一个 OpenAI 兼容 API（baseUrl + API Key + model），在聊天框输入：

```
画一张电商网购完整流程（用户下单 → 出库），标注所有卡点
```

## 架构

```
┌─────────────────────────────────────────────────────────┐
│ 用户输入 → 调度器 orchestrator                           │
│  ┌─────────┐ ┌──────────┐ ┌─────────┐                  │
│  │ 项目经理 │→│ 设计助手 │→│ 架构师  │ (按优先级串行)   │
│  └─────────┘ └──────────┘ └─────────┘                  │
│  ┌─────────┐ ┌──────────┐ ┌─────────┐                  │
│  │ 评审员  │ │ 执行代理 │ │ 文档员  │                  │
│  │(必看图) │ │(结构化) │ │(经验)  │                  │
│  └─────────┘ └──────────┘ └─────────┘                  │
│  ┌─────────┐                                            │
│  │ 小白    │ (用户视角反馈)                            │
│  └─────────┘                                            │
│ 工具执行器 toolExecutor                                │
│  ├ draw_flowchart(nodes, edges)  一次画完整张图        │
│  ├ add_nodes / add_edges / update_nodes / remove_cells│
│  ├ get_diagram_xml 读画布                              │
│  └ lintLayout 节点重叠/连线穿过/连线交叉 静态检查     │
└─────────────────────────────────────────────────────────┘
```
