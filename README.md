# Flowchart Agent — 多智能体 draw.io 流程图工具

> 一句话：用 7 个 AI 智能体 + draw.io 画布协作，让你说的"画一张流程图"自动拆解、画图、质检、优化布局、沉淀经验。

## ✨ 它能做什么

- 📝 **一句话需求** → 自动生成专业流程图，**不用手画**
- 🤖 **多智能体协作**：项目经理 / 设计助手 / 架构师 / 评审员 / 执行代理 / 文档员 / 小白
- 🛠️ **可插拔 Skill**：自带 `drawio-architecture` / `AIGuide 画图专家`，拖入 zip/.md 即可加新 Skill
- 🧠 **自动沉淀经验**：每轮对话自动总结可复用经验，弹窗让你勾选入库
- 🔍 **强制看图评审**：评审员必须调 `analyze_diagram_image` 真实看图，不能口头说"通过"
- 🎯 **仅画图模式**：跳过所有讨论直接画

### v0.2.0 新增能力

- ✅ **画图质量检测器**：6 类问题自动检测（节点重叠/连线交叉/连线穿节点/标签压节点/斜线连线/平行边重合），0-100 分评分
- 📐 **自动布局引擎**：完整 Sugiyama 分层布局算法，虚节点 + 中位数排序 + 贪心交换 + 多次随机取优
- 🔀 **智能连线路由**：5 种路由模式（libavoid 障碍避让/正交/单折点/侧边/直线），平行边自动分散
- 🎨 **画布布局优化**：左聊天右画布，工具栏新增「布局优化」面板

## 🚀 快速开始

### 下载安装

从 [Releases](https://github.com/bubu-LZY/flowchart-agent/releases) 下载最新的 `Flowchart Agent-x.y.z-Setup-x64.exe`，双击安装即可。

> 💡 安装前请完全退出旧版本（包括系统托盘图标），避免文件被占用。

### 本地开发

```bash
npm install
npm run dev                    # 启动开发版（端口 5173）
npm run build:electron         # 打包 Windows 安装包到 release/
```

打开应用后到 **设置 → 模型配置** 添加一个 OpenAI 兼容 API（baseUrl + API Key + model），在聊天框输入：

```
画一张电商网购完整流程（用户下单 → 出库），标注所有卡点
```

## 📐 画图质量体系

### 6 类质量检测

| 检测项 | 说明 | 严重程度 |
|--------|------|---------|
| 节点重叠 | 两个节点有重叠区域 | 🔴 严重 |
| 连线穿节点 | 连线穿过非端点节点 | 🔴 严重 |
| 标签压节点 | 边标签与节点重叠 | 🟡 警告 |
| 连线交叉 | 两条边交叉 | 🟡 警告 |
| 斜线连线 | 非正交样式的斜线 | 🟡 警告 |
| 平行边重合 | 同对节点多条边重合 | 🟢 提示 |

### 布局算法 v2 特性

- **虚节点（Dummy Nodes）**：长跨度边中间插入虚节点，每层只处理相邻边
- **中位数排序**：替代 barycenter 均值，抗异常值更稳定
- **贪心交换**：排序后做相邻交换后处理，确认局部最优
- **多次随机取优**：15 个随机初始排序，选交叉最少的结果
- **提前收敛检测**：连续 3 轮无改进停止，节省时间

### 连线路由模式

1. **libavoid 障碍避让** — 专业级正交路由，自动避开所有节点
2. **正交连线** — 标准直角折线（默认）
3. **单折点连线** — 只有一个弯折点，简洁
4. **侧边连接** — 从节点侧边连接，适合水平布局
5. **直线** — 直线连接（不推荐）
